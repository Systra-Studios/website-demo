# So pflegt ihr die Website mit Claude

Ihr braucht dafür keine Technik-Kenntnisse. Ihr sagt Claude, was sich ändern soll, schaut euch die Vorschau an und gebt frei. Alles andere passiert automatisch.

## Der Ablauf

| | Was ihr macht | Was automatisch passiert |
|---|---|---|
| 1 | Claude schreiben, was sich ändern soll | Claude sucht die richtige Seite und ändert sie in allen Sprachen |
| 2 | | Claude legt die Änderung als Vorschlag an (Pull Request) und schickt euch den Link |
| 3 | | Eine Vorschau-Seite wird gebaut, der Link erscheint im Vorschlag |
| 4 | Vorschau ansehen | |
| 5 | Passt alles: Button „Merge pull request“ klicken | Die Website wird neu gebaut und ist nach etwa zwei Minuten live |
| | Passt etwas nicht: Claude sagen, was anders sein soll | Claude korrigiert, die Vorschau aktualisiert sich |

## Beispiele, was ihr Claude schreiben könnt

- „Ändere auf der Startseite die Überschrift zu: Ersatzteile in Tagen statt Monaten.“
- „Ergänze auf der Seite 3D-Druck bei den Werkstoffen noch PEEK.“
- „Schreib eine neue Neuigkeit: Wir sind ab sofort nach ISO 9001 zertifiziert. Datum heute.“
- „Lege eine neue Leistungsseite für Spritzguss an, ähnlich aufgebaut wie die Seite CNC-Bearbeitung.“
- „Der Button auf der Kontaktseite soll ‚Jetzt anfragen‘ heißen.“

Ihr müsst nicht wissen, in welcher Datei etwas steht. Ein Hinweis wie „auf der Startseite“ oder „bei den Vorteilen“ reicht.

## Was ihr wissen solltet

- **Nichts geht ohne Freigabe live.** Solange niemand auf „Merge pull request“ klickt, bleibt die Website, wie sie ist.
- **Übersetzungen prüfen.** Claude übersetzt gut, aber bei Fachbegriffen sollte jemand mit der Sprache kurz drüberlesen.
- **Fehler werden abgefangen.** Fehlt eine Sprachversion, meldet die Automatik das und die Änderung geht nicht live.
- **Alles ist rückgängig zu machen.** Jede Änderung ist gespeichert. Ein Satz an Claude („Mach die letzte Änderung rückgängig“) reicht.

## Wann ihr Hilfe braucht

Für neue Seitentypen, ein anderes Layout, neue Formulare oder Änderungen am Design. Texte, Bilder, neue Seiten nach bestehendem Muster und Neuigkeiten macht ihr selbst.
